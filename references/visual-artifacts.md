Skeleton of what belongs here:

- **The gate**: build only when manipulating the mechanism produces
  insight reading can't. The manipulation must BE the cognitive skill.
  If the sim is an animation of the text, cut it. Precision over
  spectacle — a small correct widget beats an elaborate buggy set-piece.
- **Sim type taxonomy**: parameter-slider (forgetting curve, amortization),
  sequence/state-machine (handshakes, pipelines), spatial/graph
  (dependencies, trees), code sandbox (Pyodide — CDN allowlist
  verification still pending).
- **Mayer-derived form rules**: coherence, signaling, redundancy,
  segmenting — encoded as concrete CSS/layout constraints.
- **Technical floor**: single self-contained HTML, inline CSS/JS,
  cdnjs only, light-mode enforced, responsive, keyboard-accessible.
- **Predict-before-reveal wiring**: the interaction pattern spec —
  commitment control, reveal gate, elaborated feedback slot.
- **Component states**: unanswered / committed / correct / incorrect-
  with-elaboration / locked.
- **The 10–20 minute ceiling** and when to split or route to a course.
