Module 1 — Where the brightness comes from

Why it exists

Asking a chatbot to teach you mostly gets you a lecture.

A wall of text, pitched at nobody in particular, that drifts wherever your last message pulled it. You nod along, and a week later none of it stuck. Chiron is built on how good tutors actually work.

Ask an assistant to teach you

  • Starts explaining before it knows what you already know
  • Generic syllabus, same for everyone
  • Long chat turns that wander off the thread
  • “Great question!” — praise in place of feedback
  • Nothing to keep when the chat ends

Learn with Chiron

  • Opens with one scenario that shows how you currently think
  • Two or three modules built around the exact places you got stuck
  • Teaching composed in one pass, as an interactive artifact
  • Feedback on the substance of your answer, never on wording
  • A spaced-repetition deck with backs in your own words

The method

One idea, done properly.

Explanation lands when it arrives right at the wall — the specific thing you can feel you're missing — and slides off when it arrives before it. So Chiron asks just enough to get you there, then stops asking and builds.

What a course looks like

“I keep getting muddy indoor shots.”

A real turn shape from a course on camera exposure. One scenario, one honest guess, and Chiron already knows where to build.

Claude Code · chiron-course-tutor
You
Give me a proper walkthrough of exposure. My indoor shots keep coming out muddy.
Chiron
You're photographing a friend by a window at dusk. The shot is dark and blurry. You can turn exactly one dial — shutter, aperture or ISO. Which one, which way, and what goes wrong as a result?
You
ISO, up. I know it makes things brighter. Grain maybe?
Chiron
Built so your next window-at-dusk shot comes out sharp and clean. Three modules:
  1. All three dials control one thing, and each pays for it differently.
  2. Blur and depth of field are prices you choose.
  3. Grain is the third price, and often the cheapest.
Where do you think ISO's extra brightness comes from — more light, or something else?
You
Huh. The window's the same… so not more light? I don't know what it is then.
That's the wall. Module 1 is built in this turn — and it opens by quoting “the window's the same.”

What you walk away with

Not a transcript. Things that stick.

Modules built for you

Two or three interactive lessons, each opening on what you said you were stuck on — never “in this module we will…”.

A deck in your words

Chiron writes the fronts. You write every back. A spaced-repetition deck that works offline, straight from disk.

An answer of your own

At least one answer applying the idea to your situation, read and responded to — not matched against a key.

Inside a module

Built like a lesson, not a reply.

Every module is written in one pass with the whole argument in view, so it doesn't drift.

  • Predict firstSections about “what happens when” open with a prediction you commit to before reading on.
  • Real instrumentsIf the idea has a quantity you can turn, you get a control to turn it.
  • Checks that teachMultiple choice with misconception distractors, drag-to-label, ordering, numeric with tolerance.
  • InterleavedFrom module 2 on, a third of the checks pull from earlier modules, reworded.
  • Real figuresAnything that plots data comes from computed output. Sketches are labelled as sketches.
Module 2 · End check

The deck

Flashcards you actually wrote.

After each module, Chiron hands you a few card fronts. You write the backs in a sentence or two. It pushes back on substance, never polish. Everything goes into one self-contained flashcards.html.

Install

Thirty seconds, then start learning.

Chiron is a standard Agent Skill: one folder with a SKILL.md and a few reference files. No packages, no build step, no API keys.

  1. 1
    Clone it into your skills folder. Personal install works in every project; a project install travels with the repo.
  2. 2
    Start Claude Code. Skills are picked up automatically — nothing to register.
  3. 3
    Ask to be taught. “Give me a crash course on…” or just “Chiron: …”.
Works best with artifacts. Chiron also uses code execution, inline widgets and memory when they're available. Where one is missing, it does that step another way instead of skipping it.
